# CTF & Security Lab Notes

This repository contains my personal notes, scripts, and writeups from
authorized CTF challenges and intentionally vulnerable lab environments.

All testing documented here is performed in environments that I own,
control, or am explicitly authorized to use.

## Areas of Interest

- Web application security
- Cryptography
- Reverse engineering
- Digital forensics
- Network analysis
- Security automation with Python

## Repository Structure

- `web-security/` — Web security lab notes
- `cryptography/` — Cryptography exercises
- `forensics/` — Digital forensics exercises
- `reverse-engineering/` — Reverse engineering labs
- `automation/` — Python security automation

## Ethics

This repository is intended for cybersecurity education and defensive
research.

I do not use the techniques documented here against systems without
authorization.
